How to read it

      
Outer loop (i) chooses where a substring starts.

      
Inner loop (j) walks right from i, adding characters to a set. A set can’t hold duplicates, so set.contains(ch) tells us instantly whether we’ve seen the character.

      
The moment a repeat appears, the substring can’t grow, so we break and try the next start.

      
Cost: for each of n starts we may scan up to n characters, so time is O(n²). The set holds at most the alphabet size, so extra space is O(min(n, alphabet)). A sliding window brings this down to O(n).
